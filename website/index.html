Move the active window to a screen half, center it, or fill the screen.

Download for Mac ↓

Apple Silicon · macOS 13 or later

Public download not yet available. Build from source.

Installation

  1. Unzip the download and move Windower to Applications.
  2. Open Windower and grant Accessibility access in System Settings.
  3. Use the shortcuts, or choose an action from the menu bar.

How it works

Uses the window’s current display, leaving room for the Dock and menu bar. Center uses 75% of the available width and height.

Launch at Login is enabled on first launch. Change it from Windower’s menu.

Some apps limit how small their windows can be. Exit macOS full screen before using a shortcut.
